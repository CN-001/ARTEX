# ssrf —— SSRF 专项 Playbook

## 一、核心功能

| 职责 | 归属 |
|---|---|
| 题型识别、Session State、L1/L2/L3、假设与优先级 | **CTF-Analyzer-V2.0（大脑）** |
| 服务端取回行为判定、协议与端点探测、绕过技术 | **本 Skill** |
| 决定下一步验证什么、解读测试结果 | **CTF-Analyzer-V2.0** |

本 Skill 不输出题型判断、不维护假设状态、不宣布 Level 等级。

## 二、输入识别

| 输入类型 | 用途 |
|---|---|
| 含 URL 参数的请求（`?url=`、`?image=`、`?fetch=`） | 定位候选输入点 |
| 服务端返回外部资源内容的响应 | 判定服务端是否真的发起请求 |
| 报错信息（连接失败、DNS 解析失败） | 协议支持与网络层信息 |
| 已执行探测与结果 | 由 Analyzer 归类，本 Skill 解释 |

## 三、分析流程：SSRF 决策树

```text
参数值是 URL，且服务端可能取回该 URL 内容
    │
    ↓  是否有证据表明服务端发起了请求？
    │   （证据：返回内容随 URL 变化 / 报错含连接信息 / 响应头变化）
    │
    ├── 无证据 → Unknown（要求 Analyzer 补充响应对比）
    │
    └── 是
        │
        ↓  支持哪些协议？
        │
        ├── http/https → 内网探测方向
        ├── file:// → 本地文件读取（与路径穿越交叉）
        ├── gopher:// → 打内网服务（Redis / FastCGI 等）
        ├── dict:// → 端口与服务探测
        └── ldap:// / ftp:// → 其他协议利用
        │
        ↓  是否存在访问控制（白名单 / 黑名单）？
        │
        ├── 无 → 直接探测内网与元数据端点
        └── 有 → 绕过方向
              ├── DNS 重绑定（rebinding）
              ├── URL 解析差异（`@` 用户名段、`#` 片段、反斜杠）
              ├── 短链 / 重定向跟随
              ├── 进制与编码（`127.0.0.1` → `2130706433`、`0x7f.1`）
              └── 子域名截断 / 解析器不一致
        │
        ↓  高价值目标（按价值排序）
        │
        ├── 云元数据端点（169.254.169.254）→ 凭据窃取
        ├── 内网管理面板、Redis、Kubernetes API
        └── 本地端口与服务指纹
```

### 常见绕过等价表达（本地地址）

`127.0.0.1` → `localhost` / `2130706433`（十进制）/ `0x7f.1`（十六进制）/ `0177.0.0.1`（八进制）/ `[::1]`（IPv6）/ `127.1`

## 五、与 CTF-Analyzer-V2.0 的协作方式

```text
CTF-Analyzer-V2.0 判定 Web 题且存在 SSRF 方向
  → 调用 ssrf playbook
  → 本 Skill 返回取回行为判定与探测方向
  → Analyzer 汇总（更新假设、计算优先级、生成 Smart Next Step）
```

**协作纪律：** 只被 Analyzer 调用；不修改 Session State；**「参数叫 url」不等于「存在 SSRF」**——必须有服务端取回行为的证据；白名单限制证据出现时，明确返回「经典 SSRF 路径被切断」并建议 Analyzer 降级该假设、转向绕过方向。

## 六、安全边界

所有操作仅限 CTF / 靶场 / 本地实验 / 明确授权环境。**禁止针对真实云环境或真实内网执行元数据端点探测**——这类操作在真实环境会造成凭据泄漏。越界时转为 SSRF 原理讲解、网络层分段防护、元数据端点加固（IMDSv2）与授权测试流程。

## 七、自检规则

- [ ] 是否区分了「参数是 URL」（弱证据）与「服务端确实取回」（强证据）？
- [ ] 协议支持是否有 Evidence，还是仅推测？
- [ ] 是否编造了内网响应或元数据内容？
- [ ] 白名单证据出现时，是否返回了降级/淘汰信号？
