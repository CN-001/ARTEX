# 授权范围核对清单（开工前必查）

## 一、范围核对

- [ ] 授权方是谁（公司全称/平台）？
- [ ] 授权域名/ IP 段完整列表（含子域规则 `*.example.com` 是否含多级）
- [ ] 明确排除项（如 `admin.example.com`、支付接口、生产数据库）
- [ ] 授权时间窗（起止日期）
- [ ] 允许的测试类型（被动/主动/爆破？是否允许社工/物理？）
- [ ] 限速要求（每秒请求数/并发数）
- [ ] 报告渠道（平台提交/邮件/私信）
- [ ] 奖励规则（哪些等级有奖金/积分）

## 二、技术边界

- [ ] 只测授权范围，**不碰相邻资产**（同 IP 不同站、同服务器其他域名）
- [ ] 不做破坏性操作：删除/修改/写入/拒绝服务/大量注册
- [ ] 不下载用户数据（读到即止，截图脱敏）
- [ ] 不进行社工（除非授权书明确允许）
- [ ] 不使用自动爆破（除非明确允许且有限速）

## 三、存档

- [ ] scope.txt 存入任务目录
- [ ] 授权书/平台规则截图存档
- [ ] 每个漏洞的原始请求/响应存档（加密）
- [ ] 提交记录（时间/平台/状态）登记

## 四、异常处置

| 情况 | 动作 |
|---|---|
| 发现高危数据（用户库/密钥） | 立即停止，只读证明，联系平台/厂商 |
| 误触生产数据 | 立即停止，报告并说明 |
| 平台规则模糊 | 先问清楚再测 |
| 客户要求超范围 | 拒绝，要求补充授权 |
