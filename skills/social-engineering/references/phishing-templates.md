# 钓鱼邮件模板库（授权演练专用）

> 使用前提：演练授权 + 演练标识（页脚水印/专用域名/演练编号）。
> 目标：**测人**，不是搞破坏——模板要"像"但不可要求真实密码、不植入恶意载荷（演练环境除外）。

## 1. IT 安全通知类（最高点击率）

```text
主题：【IT 安全中心】您的账户将于今日 18:00 被停用
发件人：IT 服务台 <it-support@<演练域名>>
正文：
  您好：
  我们的安全扫描发现您的账户存在弱口令风险，为保护公司数据，
  系统将在今日 18:00 前强制重置密码。请于截止前完成验证，否则账户将被锁定。
  [立即验证 →]   ← 链接指向演练落地页
  —— IT 安全中心
  （本邮件为公司安全演练邮件，请勿外传；演练编号 SE-2026-xx）
```

## 2. 密码过期类（最常见钓鱼题材）

```text
主题：密码将在 24 小时后过期（跨设备同步失败）
正文：
  您的 Microsoft 365 密码违反最新安全策略，将在 24 小时内过期。
  请在过期前登录 https://<演练域名>/login 重新设置密码。
  提示：请勿在不同设备上重复输入同一密码。
```

## 3. 供应商/财务类（鱼叉高转化）

```text
主题：逐月对账单与发票（请确认）
正文：
  您好，附件为本季度对账单，请核对金额后回签。
  如对账务有疑问请联系财务：finance@<演练域名>
  [查看对账单 →]
```
> 附件用真实 PDF 模板 + 演练标识；**不装宏、不装可执行**。

## 4. HR/行政类（内部信任度高）

```text
主题：关于调整后的绩效考核规则（附件）
正文：
  各位同事：新版绩效考核细则已发布，请于本周五前阅读并提交确认。
  [打开细则 →]（演练落地页）
```

## 5. 会议邀请类（基于真实日历事件更真）

```text
主题：邀请：2026 年 Q4 安全合规培训（明天 15:00）
正文：请点击参会链接：https://<演练域名>/meeting?mtg=xxxx
```
> 可配合相似域名 + 假登录页收集"会议平台账号"，检验员工对陌生链接的警惕。

## 落地页要求（关键）

- 页面顶部/页脚固定标注：**"本页为公司安全演练页面"**
- 登录失败一次后提示"演练结束"并跳转内部安全宣传页
- 所有输入数据加密存储、只记录"提交了/未提交"，不保存明文密码
- 演练结束立即关停

## 投递质量自检

```bash
# 域名 SPF/DKIM/DMARC 配好后自测
dig TXT <演练域名>            # 看 SPF
# 用 mail-tester.com 发测试邮件，评分 ≥8 再正式开始
# 域名年龄 <30 天容易被拦：提前注册预热
```
