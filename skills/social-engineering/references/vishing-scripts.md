# Vishing 电话社工剧本（授权演练专用）

> 前提：书面授权 + 演练电话录音授权 + 演练声明模板。
> 原则：**不冒充真实领导/客户、不索要超出范围的信息、演完立刻亮明演练**。

## 剧本结构

```
① 身份钩子（建立信任）
   "您好，我是 IT 运维中心的小王，工号 8xxx，今天做设备安全巡检。"
② 背景铺垫（合理理由）
   "系统检测到您这台的杀毒软件版本旧了，需要远程协助更新一下。"
③ 紧迫感（制造时间压力）
   "今天下班前要完成 100% 巡检，不然会被审计点名。"
④ 索取点（只问范围允许的）
   "麻烦您把桌面右下角那个安全软件的版本号念一下？"
   或 "我给您发一个验证链接，点一下确认补丁状态。"
⑤ 收尾（防怀疑）
   "好了，登记完成，感谢配合，有问题直接回拨 IT 台 8xxx。"
```

## 五类常见剧本（按演练目标选用）

| 场景 | 话术要点 | 测什么 |
|---|---|---|
| IT 支持 | 远程协助/版本升级 | 员工是否核实来电身份 |
| 财务对账 | 供应商账户变更（"法人变更，请改收款账号"） | 是否走双人复核 |
| HR 入职 | 新同事要开账号/要资料 | 账号开通流程是否合规 |
| 快递/行政 | 有包裹需要本人确认 | 个人信息保护意识 |
| 安全通报 | "您的账号在异地登录" | 应急反应是否上报 |

## 演练声明模板（必须准备）

```text
"您好，刚才的电话是我们公司授权的安全演练（演练编号 SE-2026-xx），
 目的是检验大家对陌生来电的警惕性。您刚才没有提供敏感信息，做得很好/下次注意。
 本通电话已按要求记录用于演练报告，不会用于其他用途。感谢配合。"
```

## 合规红线

- 禁止对目标人员做出威胁、恐吓、诱导违法操作；
- 禁止索要真实登录密码（演练最多收集"是否点击/是否配合"）；
- 禁止冒充执法人员/银行/政府机构；
- 录音需授权；未授权只做"角色扮演彩排"不真实拨打。

## 防守方对照（蓝队速查）

- 陌生来电索要账号/操作指引 → 一律回拨官方台核实；
- 涉及转账/改账户 → 双人复核 + 线下确认；
- 来电显示可伪造（VoIP），不要信号码。
