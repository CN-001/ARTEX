# 云安全技能

## 概述

本技能提供系统化的云安全框架，涵盖AWS安全评估、Azure安全评估、GCP安全评估、云IAM权限与访问控制审计、云存储安全配置审计、云网络与WAF安全、无服务器架构安全和多云安全策略评估等核心能力。

**核心能力:**
- AWS安全 - AWS云平台安全评估
- Azure安全 - Azure云平台安全评估
- GCP安全 - GCP云平台安全评估
- 云IAM审计 - 云IAM权限和访问控制审计
- 云存储安全 - 云存储安全配置审计
- 云网络安全 - 云网络和WAF安全
- 无服务器安全 - 无服务器架构安全
- 多云安全 - 多云安全策略评估

**适用场景:**
- 云安全评估
- 云合规审计
- 云安全运营
- 云安全开发
- 云安全培训

## 快速开始

### 云安全评估流程

1. **资产发现** - 30-60 分钟
   - 发现云资产
   - 分析云架构
   - 识别关键资源

2. **配置审计** - 1-2 小时
   - 审计云配置
   - 检查安全设置
   - 评估合规性

3. **漏洞扫描** - 1-2 小时
   - 扫描云漏洞
   - 测试云安全
   - 评估风险

4. **安全加固** - 2-4 小时
   - 修复安全漏洞
   - 加强安全配置
   - 改进安全策略

## 最佳实践

### 云安全原则

1. **共享责任** - 理解云共享责任模型
2. **最小权限** - 遵循最小权限原则
3. **纵深防御** - 实施多层次防御
4. **持续监控** - 持续监控云环境
5. **合规性** - 遵守法律法规

### 常见误区

- 忽略共享责任模型
- 过度依赖云提供商安全
- 没有实施最小权限
- 缺乏持续监控
- 忽略合规要求
