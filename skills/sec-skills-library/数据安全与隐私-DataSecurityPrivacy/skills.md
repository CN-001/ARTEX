# 数据安全与隐私技能

## 概述

本技能提供系统化的数据安全与隐私框架，涵盖数据分类与分级保护、DLP数据防泄漏策略、数据脱敏与匿名化、GDPR/个保法合规评估、数据库安全与加密和隐私影响评估PIA等核心能力。

**核心能力:**
- 数据分类 - 数据分类与分级保护
- DLP - 数据防泄漏策略
- 数据脱敏 - 数据脱敏与匿名化
- 合规评估 - GDPR/个保法合规评估
- 数据库安全 - 数据库安全与加密
- 隐私评估 - 隐私影响评估PIA

**适用场景:**
- 数据安全评估
- 隐私合规审计
- 数据保护实施
- 数据治理管理
- 隐私保护培训

## 快速开始

### 数据安全评估流程

1. **数据发现** - 1-2 天
   - 发现数据资产
   - 分析数据流
   - 识别敏感数据

2. **数据分类** - 1-2 天
   - 分类数据类型
   - 评估数据价值
   - 确定保护级别

3. **安全评估** - 2-3 天
   - 评估数据安全
   - 检查访问控制
   - 测试数据保护

4. **合规审计** - 1-2 天
   - 审计合规性
   - 检查隐私保护
   - 评估风险

## 最佳实践

### 数据安全原则

1. **数据分类** - 分类数据资产
2. **最小权限** - 遵循最小权限原则
3. **加密保护** - 使用加密保护
4. **访问控制** - 实施访问控制
5. **隐私保护** - 保护用户隐私

### 常见误区

- 没有数据分类
- 忽略数据脱敏
- 缺乏访问控制
- 没有隐私评估
- 忽略合规要求
