# 威胁情报技能

## 概述

本技能提供系统化的威胁情报框架，涵盖威胁情报馈入与TAXII/STIX管理、MISP平台部署与威胁情报共享、APT组织分析与归因和威胁情报驱动安全运营等核心能力。

**核心能力:**
- 情报馈入 - 威胁情报馈入与TAXII/STIX管理
- MISP平台 - MISP平台部署与威胁情报共享
- APT分析 - APT组织分析与归因
- 情报驱动 - 威胁情报驱动安全运营

**适用场景:**
- 威胁情报分析
- 威胁情报平台部署
- 威胁情报共享
- 情报驱动安全运营
- APT组织分析

## 快速开始

### 威胁情报流程

1. **情报收集** - 持续进行
   - 收集威胁情报
   - 监控情报源
   - 更新情报数据

2. **情报分析** - 1-2 小时
   - 分析威胁情报
   - 评估情报质量
   - 识别威胁模式

3. **情报共享** - 30-60 分钟
   - 共享威胁情报
   - 发布情报报告
   - 协作情报分析

4. **情报应用** - 持续进行
   - 应用威胁情报
   - 改进安全防御
   - 优化安全运营

## 最佳实践

### 威胁情报原则

1. **质量优先** - 确保情报质量
2. **及时更新** - 及时更新情报
3. **协作共享** - 协作共享情报
4. **应用驱动** - 应用驱动分析
5. **持续改进** - 持续改进流程

### 常见误区

- 忽略情报质量
- 没有及时更新
- 缺乏情报共享
- 没有应用情报
- 缺乏持续改进
