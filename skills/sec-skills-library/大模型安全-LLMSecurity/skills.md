# 大模型安全技能

## 概述

本技能提供系统化的大模型安全框架，涵盖LLM提示注入与安全防护、LLM数据泄露与隐私保护、AI供应链安全、大模型红队测试、AI Agent权限与访问控制、模型对抗攻击与防御、模型输出安全与幻觉检测、AI应用安全配置审计、联邦学习安全和多模态AI安全等核心能力。

**核心能力:**
- 提示注入 - LLM提示注入攻击和防护
- 数据泄露 - LLM数据泄露和隐私保护
- 供应链安全 - AI供应链安全
- 红队测试 - 大模型红队测试
- 权限控制 - AI Agent权限和访问控制
- 对抗攻击 - 模型对抗攻击和防御
- 输出安全 - 模型输出安全和幻觉检测
- 配置审计 - AI应用安全配置审计
- 联邦学习 - 联邦学习安全
- 多模态安全 - 多模态AI安全

**适用场景:**
- AI安全评估
- LLM漏洞测试
- AI红队演练
- AI安全开发
- AI合规审计

## 快速开始

### LLM安全评估流程

1. **威胁建模** - 1-2 小时
   - 识别AI应用威胁
   - 分析攻击面
   - 确定评估重点

2. **漏洞测试** - 2-4 小时
   - 执行提示注入测试
   - 测试数据泄露风险
   - 评估供应链安全

3. **红队测试** - 4-8 小时
   - 执行红队攻击
   - 测试防御机制
   - 评估安全效果

4. **安全加固** - 2-4 小时
   - 修复发现漏洞
   - 加强安全配置
   - 改进防御机制

## 最佳实践

### LLM安全原则

1. **安全设计** - 从设计阶段考虑安全
2. **最小权限** - 遵循最小权限原则
3. **持续监控** - 持续监控AI系统
4. **透明度** - 保持AI系统透明
5. **合规性** - 遵守法律法规

### 常见误区

- 忽略提示注入风险
- 没有数据保护措施
- 缺乏供应链安全
- 没有进行红队测试
- 忽略输出安全
