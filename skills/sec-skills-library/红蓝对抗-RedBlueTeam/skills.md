# 红蓝对抗技能

## 概述

本技能提供系统化的红蓝对抗框架，涵盖红队评估方法论、蓝队防御与检测、紫队协作评估、BAS攻击模拟平台和闭环防御改进等核心能力。

**核心能力:**
- 红队评估 - 红队评估方法论
- 蓝队防御 - 蓝队防御与检测
- 紫队协作 - 紫队协作评估
- BAS - BAS攻击模拟平台
- 防御改进 - 闭环防御改进

**适用场景:**
- 红队演练
- 蓝队防御
- 紫队协作
- 攻击模拟
- 防御改进

## 快速开始

### 红蓝对抗流程

1. **对抗准备** - 1-2 天
   - 确定对抗范围
   - 制定对抗计划
   - 准备对抗工具

2. **红队攻击** - 1-2 周
   - 执行红队攻击
   - 模拟真实攻击
   - 收集攻击数据

3. **蓝队防御** - 1-2 周
   - 检测攻击行为
   - 分析攻击技术
   - 响应安全事件

4. **紫队评估** - 1-2 天
   - 评估对抗效果
   - 分析检测差距
   - 改进防御策略

## 最佳实践

### 红蓝对抗原则

1. **授权性** - 确保获得对抗授权
2. **真实性** - 模拟真实攻击
3. **协作性** - 红蓝紫队协作
4. **可追溯性** - 记录对抗过程
5. **改进性** - 持续改进防御

### 常见误区

- 过度依赖自动化工具
- 忽略团队协作
- 没有评估效果
- 缺乏持续改进
- 违反道德和法律
