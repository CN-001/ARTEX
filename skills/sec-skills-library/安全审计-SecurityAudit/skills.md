# 安全审计技能

## 概述

本技能提供系统化的安全审计框架，涵盖等级保护合规审计、配置安全审计、安全架构审计、云安全审计、容器安全审计、网络安全合规评估和AI Agent安全审计等核心能力。

**核心能力:**
- 等级保护合规 - 等保2.0合规审计
- 配置安全审计 - 系统配置安全审计
- 安全架构审计 - 安全架构评估
- 云安全审计 - 云环境安全审计
- 容器安全审计 - 容器环境安全审计
- 网络安全合规 - 网络安全合规评估
- AI安全审计 - AI应用安全审计

**适用场景:**
- 安全合规审计
- 安全评估和认证
- 安全治理和管理
- 风险评估和管理
- 安全培训和咨询

## 快速开始

### 安全审计流程

1. **审计准备** - 1-2 天
   - 确定审计范围
   - 制定审计计划
   - 准备审计工具

2. **审计执行** - 3-5 天
   - 收集审计证据
   - 执行安全测试
   - 分析审计结果

3. **审计报告** - 1-2 天
   - 编写审计报告
   - 提供改进建议
   - 跟踪整改情况

## 最佳实践

### 安全审计原则

1. **全面性** - 覆盖所有审计范围
2. **准确性** - 确保审计结果准确
3. **可追溯性** - 记录审计过程
4. **及时性** - 及时完成审计
5. **合规性** - 遵守法律法规

### 常见误区

- 过度依赖自动化工具
- 忽略业务逻辑审计
- 没有评估风险影响
- 缺乏整改跟踪
- 忽略持续改进
